Critical

  1. Marketing site loads GTM/GA before consent
  • Category: Security / Compliance
  • Issue: frontend/index.html injects GTM + gtag/js in <head> before any choice. Consent Mode defaults to denied, but the scripts still load. The banner copy also says “By continuing, you agree…” which is not valid UK GDPR/PECR
    consent.
  • Impact: A GDPR product with broken first-party consent is a trust and regulatory risk.
  • Remediation: Load analytics only after Accept (or Consent Mode + no GTM until opt-in). Offer Accept / Reject / Preferences. Align copy with what actually happens.
  • Pillar: Security

  2. JWT stored in localStorage
  • Category: Security
  • Issue: Portal auth (Login.tsx, App.tsx, Dashboard.tsx) keeps the session JWT in localStorage.
  • Impact: Any XSS becomes full account takeover.
  • Remediation: Prefer httpOnly, Secure, SameSite cookies (or short-lived access + refresh). Pair with a real CSP.
  • Pillar: Security

  3. No CloudTrail / GuardDuty / Security Hub
  • Category: Security
  • Issue: Still absent from Terraform (also open in docs/audits/2026-07-comprehensive-findings.md).
  • Impact: No account audit trail or threat detection if AWS is compromised.
  • Remediation: Add multi-region CloudTrail + GuardDuty (+ Security Hub) under terraform/persistent/.
  • Pillar: Security

  4. CI uses long-lived IAM access keys
  • Category: Security
  • Issue: terraform/persistent/iam_cicd.tf creates gitlab-ci-deployer + static access keys, not OIDC.
  • Impact: Leaked keys work until manually rotated.
  • Remediation: GitLab OIDC → AssumeRoleWithWebIdentity, scoped to project/branch.
  • Pillar: Security

  High

  5. Paid dashboard features are mostly mock UI
  • Category: Maintainability / Trust
  • Issue: Consent logs, ROPA, staff training, certificate/badge, scheduled scans, webhooks are hardcoded useState demo data in Dashboard.tsx. Marketing sells Consent Manager, Vendor Register, Certificate, etc.
  • Impact: Paying customers get blurred theatre, not product. For a compliance SaaS this is a credibility problem.
  • Remediation: Ship one vertical at a time with real API persistence, or mark remaining tabs “Coming soon” and stop selling them on the landing page until they work.
  • Pillar: Operational Excellence

  6. Fabricated social proof and fine calculator
  • Category: Maintainability / Trust
  • Issue: Testimonials (Sarah T., Eleanor B., etc.), “23 / 30 founding spots (Updated Today)”, and fixed £50k/£25k/£35k “fine exposure” numbers look invented. ICO fines are not additive line items like that.
  • Impact: Misrepresentation risk; weakens trust for a compliance brand.
  • Remediation: Use real quotes or remove. Drop fake scarcity. Replace calculator with ICO-aligned educational framing (turnover %, aggravating factors) or a soft “risk factors” checklist without fake GBP totals.
  • Pillar: Operational Excellence

  7. Contact / audit request form is a stub
  • Category: Reliability
  • Issue: frontend/main.js handleFormSubmit only console.logs and shows success — no API/SES.
  • Impact: Lost leads; users think you received their request.
  • Remediation: POST to API + SES (or Formspree/etc.) and only show success on 2xx.
  • Pillar: Reliability

  8. No CSP / security headers on static frontends
  • Category: Security
  • Issue: Helmet covers the API; marketing + portal via CloudFront have no CSP / frame / referrer policy (still open from prior audit).
  • Impact: Weaker XSS defense, especially with innerHTML in the scan widget.
  • Remediation: CloudFront response headers policy; tighten scan UI to textContent / DOM APIs.
  • Pillar: Security

  9. Production RDS is single-AZ db.t3.micro
  • Category: Reliability / Cost
  • Issue: terraform/environments/production/rds.tf has multi_az = false.
  • Impact: AZ failure = full SaaS outage.
  • Remediation: Multi-AZ for prod; define RPO/RTO and test restore from backups.
  • Pillar: Reliability

  10. Schema still applied via prisma db push
  • Category: Reliability
  • Issue: No migration history; startup uses db push.
  • Impact: Schema drift and unsafe deploys across environments.
  • Remediation: prisma migrate dev → commit migrations → migrate deploy in start.sh.
  • Pillar: Reliability
